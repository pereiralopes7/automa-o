# automação com selenium
#Primeiro projeto de automação com Selenium
#Esse foi o primeiro projeto de automação que fiz utilizando Selenium, com o objetivo de automatizar o processo de login em um site de teste. O projeto foi desenvolvido em Python e utiliza o Selenium WebDriver para interagir com os elementos da página web.
#Com isso, consegui automatizar o processo de login, preenchendo os campos de usuário e senha, e clicando no botão de login. Além disso, o projeto também inclui a verificação de mensagens de sucesso.
#Aprendi muito com esse projeto, sobre as ferramentas do Selenium como time.sleep, driver.quit,send_keys.
